# Aster Mail Modules

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Официальный каталог модулей для [Aster Mail](https://github.com/darxfame/aster-mail)
от [darxfame](https://github.com/darxfame). Репозиторий содержит исходники модулей,
SDK и документацию для разработчиков. Здесь же можно предложить собственный модуль.

[Участие](CONTRIBUTING.md) · [История изменений](RELEASE_NOTES.md)

## Модули

| Модуль | Возможности | Документация |
| --- | --- | --- |
| Контур.Толк | Создание комнат, корпоративный вход, настройка сервера и открытие встреч в десктопном приложении | [ktalk](ktalk/README.md) |

Модули подключаются в релизной версии Aster Mail с поддержкой модулей.
Сведения о совместимости поставляются вместе с записью каталога.

## Установка

1. Откройте «Настройки → Модули» в Aster Mail.
2. Выберите модуль из каталога и ознакомьтесь с его описанием и разрешениями.
3. Подтвердите установку и отдельно включите модуль для нужного аккаунта.
4. Настройте подключение по инструкции модуля.

Источник каталога — [catalog.json](catalog.json). Перед установкой клиент повторно
проверяет закреплённый коммит, SHA-256 пакета и разрешения. Обновления устанавливаются
явно, с повторной проверкой. Ключи и сессии хранятся в зашифрованном хранилище Aster Mail.

## Разработка

Для локальных проверок нужен Node.js 22 или новее. Сторонние npm-зависимости
для этих проверок не требуются.

```sh
git clone https://github.com/darxfame/aster-mail-modules.git
cd aster-mail-modules
npm ci
npm run check
npm test
npm run check:catalog
```

Каждый модуль находится в отдельной папке и содержит `module.json`, готовые
браузерные ресурсы и лицензию. Код модуля работает в изолированной среде Aster Mail;
доступ к приложению и внешним сервисам ограничен заявленными разрешениями SDK.
