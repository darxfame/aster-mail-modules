# v0.1.10

## Изменения

- Исправлена ложная ошибка занятого адреса: успешный ответ Толка с настройками по умолчанию больше не блокирует создание новой комнаты.
- В настройках модуля видны адрес и время последней попытки, результат предварительной проверки, создания и последующей проверки комнаты.
- Результаты сохраняются после перезапуска и доступны при ошибке до создания комнаты.
- Баги заняли все случайные комнаты — выселили проверкой документов.

## Установка

В «Настройки → Модули» обновите Контур.Толк до 0.1.8 с сохранением настроек.
После обновления создайте комнату из новой встречи. Сведения о последней попытке доступны в настройках Толка.
Если результат записи неизвестен, используйте «Проверить комнату»: повторной записи не будет.

# v0.1.9

## Изменения

- Ошибка предварительной проверки комнаты показывает HTTP-статус и сообщает, что запрос создания не отправлялся.
- Отказ авторизации, отсутствие доступа, ограничение частоты и неизвестный результат создания различаются в сообщениях.
- Сохранённая SSO-сессия больше не выглядит подтверждением права создавать комнаты.
- Баги скрывали причины отказа — теперь отвечают по существу.

## Установка

В «Настройки → Модули» обновите Контур.Толк до 0.1.7 с сохранением настроек.
Если создание снова завершится ошибкой, сообщите её новый текст с HTTP-статусом.
Неподтверждённую комнату проверяйте через настройки; создание автоматически не повторяется.

# v0.1.8

## Изменения

- Корпоративный вход Толка допускает HTTPS-переход к серверу организации без добавления домена IdP в пакет.
- Начало входа остаётся на app.ktalk.ru; сохраняется только сессия настроенного пространства Толка, а не корпоративного IdP.
- Багам выдали гостевой пропуск — только на выход.

## Установка

Обновите Aster Mail до 0.2.8 или новее, затем обновите Контур.Толк до 0.1.6 с сохранением настроек.
Нажмите «Войти через SSO пространства», выберите SSO в Толке и введите адрес пространства, указанный в настройках.

# v0.1.6

## Изменения

- Добавлен полный сброс сервера, API-ключа, сессии и локальных настроек комнат с подтверждением прямо на кнопке. Неизвестный результат создания сначала нужно проверить.
- Для SSO требуется адрес пространства компании. Кнопка не запускает общий вход в аккаунт Контура через app.ktalk.ru.
- Добавлен сервер auth.kontur.ru для пространств, использующих вход Контура. Сообщение о неподдерживаемом сервере теперь предлагает обновить модуль или обратиться к его автору.
- Баги искали выход через SSO — нашли кнопку сброса.

## Установка

В Aster Mail 0.2.6 или новее обновите Контур.Толк до 0.1.4 через «Обновить с сохранением настроек».
Для корпоративного входа укажите адрес пространства компании вида company.ktalk.ru и нажмите «Войти через SSO пространства».
Чтобы очистить настройки, откройте панель Толка, нажмите «Сбросить все настройки Толка» и подтвердите сброс.
Обновление пакета и переустановка приложения сами по себе сохраняют настройки.

# v0.1.5

## Изменения

- В новой встрече осталась одна кнопка «Создать комнату»: ссылка сразу добавляется в место и описание встречи, сохраняя введённую повестку.
- Настройки входа и API-ключа доступны отдельно в разделе «Модули». Добавлена подсказка, где администратор Толка создаёт ключ пространства.
- Повторное нажатие в том же черновике использует уже созданную комнату. Неопределённый результат создания можно проверить в настройках.
- Баги пришли на встречу без ссылки — теперь им её подставляют автоматически.

## Установка

Обновите Aster Mail до 0.2.5 или новее, затем в каталоге выберите «Обновить с сохранением настроек» для Контур.Толк 0.1.3.
В настройках модуля укажите сервер пространства и войдите через корпоративный аккаунт либо сохраните ключ API с правами чтения и изменения комнат.
Для перехода по готовой ссылке ключ не нужен.
