# v0.1.6

## Изменения

- Добавлен полный сброс сервера, API-ключа, сессии и локальных настроек комнат с подтверждением прямо на кнопке. Неизвестный результат создания сначала нужно проверить.
- Для SSO требуется адрес пространства компании. Кнопка не запускает общий вход в аккаунт Контура через app.ktalk.ru.
- Добавлен сервер auth.kontur.ru для пространств, использующих вход Контура. Сообщение о неподдерживаемом сервере теперь предлагает обновить модуль или обратиться к его автору.
- Баги искали выход через SSO — нашли кнопку сброса.

## Установка

В Aster Mail 0.2.6 или новее обновите Контур.Толк до 0.1.4 через «Обновить с сохранением настроек».
Для корпоративного входа укажите адрес пространства компании вида company.ktalk.ru и нажмите «Войти через SSO пространства».
Чтобы очистить настройки, откройте панель Толка, нажмите «Сбросить все настройки Толка» и подтвердите сброс.
Обновление пакета и переустановка приложения сами по себе сохраняют настройки.

# v0.1.5

## Изменения

- В новой встрече осталась одна кнопка «Создать комнату»: ссылка сразу добавляется в место и описание встречи, сохраняя введённую повестку.
- Настройки входа и API-ключа доступны отдельно в разделе «Модули». Добавлена подсказка, где администратор Толка создаёт ключ пространства.
- Повторное нажатие в том же черновике использует уже созданную комнату. Неопределённый результат создания можно проверить в настройках.
- Баги пришли на встречу без ссылки — теперь им её подставляют автоматически.

## Установка

Обновите Aster Mail до 0.2.5 или новее, затем в каталоге выберите «Обновить с сохранением настроек» для Контур.Толк 0.1.3.
В настройках модуля укажите сервер пространства и войдите через корпоративный аккаунт либо сохраните ключ API с правами чтения и изменения комнат.
Для перехода по готовой ссылке ключ не нужен.

# v0.1.1

## Изменения

- Добавлен модуль Контур.Толк: создание комнат, корпоративный вход и API-ключ, свои серверы и ссылки в черновике встречи.

модулей. После установки включите модуль и настройте сервер и корпоративный вход
либо API-ключ с правами чтения и изменения комнат.
