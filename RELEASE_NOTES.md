# v0.1.2

## Изменения

- Обновлены описание репозитория и инструкции установки модулей через релиз Aster Mail.
- Добавлено руководство по разработке, оформлению и публикации модулей.
- Оформлены правила pull request, проверки безопасности и шаблоны предложений и ошибок.
- Баги тоже прислали PR — попросили пройти проверку на выходе.

## Установка

Используйте каталог в релизной версии Aster Mail с поддержкой модулей.
После установки отдельно включите модуль для нужного аккаунта и настройте подключение.

# v0.1.1

## Изменения

- Добавлен модуль Контур.Толк: создание комнат, корпоративный вход и API-ключ, свои серверы и ссылки в черновике встречи.
- Добавлен запуск десктопного Толка по нажатию «Подключиться» в совместимой сборке Aster Mail.
- Добавлены SDK, правила оформления и подключения, каталог с закреплёнными версиями и правила предложений модулей сообщества.
- Секреты используют зашифрованное хранилище Aster Mail; неопределённое создание комнаты не повторяется.
- Баги попросили отдельную комнату — ссылку им пока не выдали.

## Установка

Подключите «Контур.Толк» из каталога в релизной версии Aster Mail с поддержкой
модулей. После установки включите модуль и настройте сервер и корпоративный вход
либо API-ключ с правами чтения и изменения комнат.

# v0.1.0

## Изменения

- Создан отдельный репозиторий для модулей Aster Mail.
- Добавлены правила разработки с доступом к актуальным исходникам и правилам Aster Mail.

Разместите репозиторий в папке `aster-mail-modules` внутри рабочей копии Aster Mail.
