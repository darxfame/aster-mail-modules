# v0.1.1

## Изменения

- Добавлен модуль Контур.Толк: создание комнат, корпоративный вход и API-ключ, свои серверы и ссылки в черновике встречи.
- Добавлен запуск десктопного Толка по нажатию «Подключиться» в совместимой сборке Aster Mail.
- Добавлены SDK, правила оформления и подключения, каталог с закреплёнными версиями и правила предложений модулей сообщества.
- Секреты используют зашифрованное хранилище Aster Mail; неопределённое создание комнаты не повторяется.
- Баги попросили отдельную комнату — ссылку им пока не выдали.

## Установка

Нужна ветка `codex/modules` Aster Mail с расширением SDK из `host/ktalk-sdk.patch`.
В стабильном Aster Mail `0.1.33` платформа модулей отсутствует.
Подключите с GitHub этот репозиторий, ref `v0.1.1`, папка `ktalk`; затем включите модуль
и настройте сервер и корпоративный вход либо API-ключ с правами чтения/изменения комнат.
