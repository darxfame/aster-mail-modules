# Материалы разработки SDK

В этой папке сохранён патч исходников Aster Mail для сопровождения возможностей
`meeting.launch`, `auth.session` и передачи кодов ошибок через Electron contextBridge.
Базовый коммит и SHA-256 файла патча указаны в `provenance.json`.
Это технический артефакт разработчика, а не установщик модулей.

Пользователи получают SDK с релизом Aster Mail и устанавливают модули через каталог.
Ручное применение патча для установки модуля не требуется.

Контракты возможностей описаны в [документации SDK](../docs/sdk/extensions.md).
Fingerprint пакета и его требования к клиенту хранятся отдельно в `catalog.json`.
