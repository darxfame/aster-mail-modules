Настройки подключения

Для корпоративного SSO укажите адрес пространства компании, например company.ktalk.ru. Вход выполняется в это пространство Толка.

Ключ API не обязателен: можно войти через SSO пространства кнопкой ниже.

Ключ создаёт администратор Толка: «Управление» → «API ключи» → «Добавить». Попросите права на чтение и изменение комнат. Для входа по готовой ссылке ключ не нужен.

Удаление сессии завершает вход. Чтобы также очистить сервер, API-ключ и настройки комнат, используйте полный сброс.

До 24 латинских букв и цифр. Буквы станут строчными. Можно оставить пустым. К префиксу добавляются 32 случайных символа.

Последняя попытка создания

Показаны только результат и признаки ответа. Токены, имена участников и сырые ответы не сохраняются в журнале проверки.

Результат создания
